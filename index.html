터치 데스크 램프

손끝 한 번으로 켜지는 빛

버튼 없이 터치만으로 켜고 끄는 미니멀 데스크 램프입니다. 한 번 터치하면 켜고 끄고, 두 번 터치하면 밝기를 조절합니다.

기능 보기 문의하기 GitHub ↗

기능

01

한 번 터치

터치 한 번으로 램프를 켜고 끕니다. 스위치는 없습니다.

입력
터치 1회
동작
점등, 소등
반응
LED

02

두 번 터치

두 번 터치하면 밝기를 조절합니다. 필요한 만큼만 밝힙니다.

입력
터치 2회
동작
밝기 조절
반응
LED

03

웹페이지 반응

터치 길이에 따라 켜지고 꺼질 때 화면 UI도 함께 반응합니다.

입력
터치 길이
동작
점등, 소등
반응
화면 UI

소개

LED를 담은 슬라이드 하우징 위에 반투명 필라멘트 확산판을 얹어 빛을 부드럽게 퍼뜨립니다. 아두이노와 빵판은 커버와 벽 뒤에 두어 눈에 보이지 않습니다.

키워드는 Minimal, Touch, Warm light입니다. 색은 Nordic Linen, Ash Wood, Pine Smoke, Walnut 네 가지 안에서만 씁니다.
